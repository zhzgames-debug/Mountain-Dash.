# Mountain Dash — Gilgit Adventure

Android-only endless runner with a bright, reference-matched Danyor/Gilgit visual direction: mountain valley, road perspective, village buildings, Danyor sign, two-lane/three-lane runner gameplay, coins, diamonds, rocks, traffic, jump and slide controls.

## Build on GitHub
1. Upload the contents of this folder to the root of a GitHub repository (not the ZIP itself).
2. Open **Actions** → **Build Mountain Dash APK**.
3. Tap **Run workflow** or push to `main`.
4. Open the successful run and download the `mountain-dash-debug-apk` artifact.

The workflow uses JDK 17 and Gradle 8.9 for a reproducible build. The in-game art has been sanitized to remove phone/WhatsApp numbers.
